## What are blade Component?

Blade components are reusable UI pieces.

Instead of repeating the same HTML again and again, you put it once in a component and reuse it everywhere.

**Think of them like:**

_"HTML Functon"_

The problem components solve

_Without components:_

```html
<button class="btn btn-primary">Save</button>
<button class="btn btn-primary">Update</button>
<button class="btn btn-primary">Delete</button>
```

If the design changes -> you must edit every file.

## Working with Blade Component

### 1. Create a component

```bash
php artisan make:component Button
```

_This Create 📁:_ resources\views\components\button.blade.php

### 2. Write the component view

```php
@props(['type', 'text'])
<button class="btn btn-{{ $type ?? 'primary' }}">
    {{ $text ?? 'Button' }}
</button>
```

_Here:_

`$type` and `$text` are props

Props are values passed to the component

### 3. Use the component

```php
<x-button type= "primary" text = "Save"/>
<x-button type= "success" text = "Update"/>
<x-button type= "danger" text = "Delete"/>
```

- ✅ Clean
- ✅ Reusable
- ✅ Maintainable

#### What are props?

Props are data you pass into components.

Just like function arguments:

```php
function button ($type, $text){}
```

**_Blade Version_**

```php
<x-button type = "primary" text= "Save"/>
```

Another real example: Input componet

```php
<input
type = "{{$type ?? 'text'}}"
name = "{{$name}}"
class= "form-control"
/>
```

**_Usage_**

```php
<x-input name="email" type = "email"/>
<x-input name="password" type = "password"/>
```

#### Why component are important!!

- ✅ Reusability
    - Write once, use everywhere.
- ✅ Consistency
    - Same UI across the app.
- ✅ Clear Blade files
    - Less HTML noise
- ✅ Real-World standard
    - Almost every professional Laravel app uses components.

## Key Rules to Remember

**Components live in resources/views/componenets**

Used with `<x-.../>`

Props are passed as attributes

Components are presentation only (no bussiness logic)

### One Line Summary

> Blade components let you reuse UI pieces like functions for HTML.
