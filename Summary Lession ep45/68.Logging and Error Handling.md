## Log and Error Handling

**What is Logging?**

> Logging = writing information about what happens in your app to files

Laravel uses logs to record:

- Errors
- Warnings
- Important events
- Debugging info

Instead of dd() or echo, logs are what real appications use.

**Where are logs stored?**

`storage/logs/laravel.log`

Every log entry goes there (unless configured otherwise).

### Basic Loggin in Laravel

Laravel provides the Log facade.

```php
use Illuminate\Support\Facades\Log;
```

#### Common log levels (important)

```php
Log::info('User Created');
Log::warning('Something look wrong');
Log::warning('Something failed');
```

### Usage Level

| Level   | When to use              |
| ------- | ------------------------ |
| info    | Normal events            |
| Warning | Suspicious but not fatal |
| error   | Something broke          |

## Real Example (Controller)

```php
public function store(Request $request){
    Log::info('Post Creation Started');

    Post::create([...]);

    Log::info('Post Created successfully');
}
```

👉 This helps you track what happened in production.

### Why NOT `dd()` in production?

- Stops execution
- Exposes data
- Crashes user experince

**_Logs:_**

- don't stop the app
- don't expose data
- help debug later

## 2. Error Handling in Laravel

> Laravel already handles error for us.

If an error happens:

- Laravel catches it
- Show a friendly error page (in Production)
- Write details to the log

Try-Catch (manual error handling)

**Use only `try/catch` wehn:**

- We expect something might fail
- We want custom behavior

**Example**

```php
try{
    Post::create([...]);
}catch(\Exception $e){
    Log::error($e->getMessage());

    return back()->with('error','Something wen wrong');
}
```

### Debugging with Logs (Real World)

Instead of :

```php
dd($user);

```

_Use:_

```php
Log::info('User data',$user->toArray());
```

This is works:

- in background jobs
- in API
- in Production

### Online Summary:

> Logging helps us understand what happened in our application without stoping it, and error handling ensures users don't see crashes.
