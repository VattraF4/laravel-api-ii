### Returning JSON Responses & Status Codes (Laravel APIs)

### 1. The Default Behavior (important)

**Laravel automatically converts arrays and models to JSON in API routes.**

```php
return [
    'message' => 'Hello API'
]
```

**Response:**

```json
{
    "message": "Hello API"
}
```

📌**Teaching Line:**

> > "if you return an array in api.php, Laravel returns JSON."

### 2. Return Eloquent Models

```php
return Post::all();
```

**Laravel returns:**

- JSON
- With correct headers
- without extra work

**⚠️ Explain:**

> > "This works, but it's not always the best practice - we'll improve it later with API Resources."

### 3. Using `response()->json()`

Use this when you want control.

```php
return response()->json([
    'success'=>true,
    'data'=>$post
],200);
```

⚠️ **Use this when:**

- You want to set a status code.
- You want a consistent structure.

### 4. HTTP Status Codes

| Code | Meaning          | When to use          |
| ---- | ---------------- | -------------------- |
| 200  | OK               | Successful Request   |
| 201  | CREATE           | Resource Create      |
| 204  | No Content       | Deleted successfully |
| 400  | Bad Request      | Invalid Request      |
| 401  | Unauthorized     | Not logged in        |
| 403  | Forbidden        | No permission        |
| 404  | Not Found        | Resource Missing     |
| 422  | Validation Error | Invalid input        |
| 500  | Server Error     | App Crash            |

### 5. Real API Example

✅ Success (create)

```php
return response()->json([
    'message'=>'Post created successfully',
    'post'=> $post
],201);

```

❌ Validation Error

```php
return response->json([
    'message' => 'Validation failed',
    'errors' => $validator->errors()
],422);
```

Explaination:

- Frontend reads 422
- Frontend show errors
- No redirect

❌ Unauthorized

```php
return response()->json([
    'message' => 'Unauthorized'
],401);
```

❌ Forbideen

```php
return response() ->json([
    'message' => 'You cannot update this post'
],403);
```

### 6. Deleting a Resouce ( Correct Way)

```php
$post = Post::findOrFail($id);
$post->delete();
return response->json([null,204])
```

📌 Teaching Line:

> > "204 means success - but no body."

### 7. Consistent API Response Structure (Best Practice)

**Here is How to standardize:**

```json
{
    "success": true
    "message":"Post create",
    "data":$post
}
```

**Error**

```json
{
     "success": false
    "message":"Validation failed",
    "error":{}
}
```
