### Return Nest Relationship in API response (Laravel 12 - REST API Context)

---

### What does "return nested relationships" mean?

It means returning related data inside the mai API response, instead of returning only the main model.

**Example Goal:**

A post API response that also includes:

- The author (user)
- The comments
- The comment authors

Basic Example (Post -> User)

#### Relationship

- Post Model

```php
public function user(){
    return $this->belongsTo(User:class);
}
```

- PostController

```php
//Controller
$post = Post::with('user')->get();
```

- Response shap

```json
[
    {
        "id": 1,
        "title": "First Post",
        "user": {
            "id": 3,
            "name": "Ra Vattra"
        }
    }
]
```

📌 User is nested inside each post.

### Nested inside nested (Post->Comment->User)

### Relationship

- Model Post.php

    ```php
    public function comments(){
        return $this->hasMany(Comment::class);
    }
    ```

- Model Comment.php

    ```php
    public function user(){
        return $this->belongsTo(User::class);
    }
    ```

- Controller

```php
$post = Post::with('comments.user')->get();
return response()->json($posts);
```

- Result: Json Response
    - Each Post include:
        - comments
        - each comment includes its author

📌 This is true nested data.

### Why Eagar Loading is **required** ?

- ❌ Bad (N+1 problem)

```php
$posts = Post::all(); // Lazy loading
```

Then Laravel runs extra queries for every post.

✅ Correct:

```php
$posts = Post::with('user','comments.user')->get();
```

- One query per relationship
- Fast and scalable APIs

### Important APIs Rule

---

> Relationships must be loaded in the controller, not accessed lazily in the response.

---

### When to user nested relationships?

**Use Them When :**

- Fronted need related data immediately
- You want fewer API requests
- You're building mobile or SPA APIs

**Avoid Them When:**

- Data is very large
- Relationship is rarely needed

**One-line takeway**
- Returning nested relationships means embedding related inside the API respone
- Using Eager Loading.
