### API Resource Controllers (Laravel 12)

### 1. What is an API Resource Controller ?

An API Resource Controller is a controller designed only for APIs.

**Key Idea:**

- No views
- No create() or edit() function.
- Only JSON responses

Follows REST convention

**📌 Final Line**

> > "API resource controllers exist because APIs don't render pages"

### 2. Creating an API Resource Controller

```php
php artisan make:controller Api/PostController --api
```

This generates only:

- index()
- store()
- show()
- update()
- destroy()

- ❌ No create()
- ❌ No edit()

### 3. Connecting It to Routes

**In routes/api.php**

```php
\App\Http\Controllers\Api\PostController;
Route::apiResource('posts',PostController::class);
```

This creates all RESTful API routes automatically,

### Basic Controller Example

```php
use App\Models\Post;
use Illuminate\Http\Request;
```

This creates all RESTful API routes automatically.

### 4. What Routes Are Generated?

| Method   | URL               | Controller Method |
| -------- | ----------------- | ----------------- |
| GET      | /api/posts        | store             |
| POST     | /api/posts        | store             |
| GET      | /api/posts/{post} | show              |
| PUT/PATH | /api/posts/{post} | show              |
| DELETE   | /api/posts/{post} | show              |

**📌Emphasize:**

> "Same URL, different HTTP method."

### 5. Basic Controller Example

```php
use App\Http\Controllers\Controller;
use Illuminate\Http\Request;

class PostController extends Controller{
    public function index(){
        return Post::all();
    }
    public function store(Request $request){
        $post = Post::create($request ->all());
        return response()->json($post,201);
    }
    public function show (Post $id){
        return $post;
    }
    public function update(Request $request, Post $post){
        $post->update($request->all());
        return $post;
    }
    public function destroy(Post $post){
        $post -> delete();
        return response()->json(null, 204);

    }

}
```

### 6. Why Use API Resource Controllers?

\*Explain benefits:

- Clean, Prdictable Structure
- REST-compliant by default
- Easy to maintain
- Easy for frontend teams to understand.
