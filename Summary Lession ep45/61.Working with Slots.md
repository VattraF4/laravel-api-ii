## What are Blade slots?

> Slots allow you to pass HTML content into a Blade Component.

If Props are for small values, slots are for blocks of content.

**Why do we need slots?**

Props are great for this:

```php
<x-button text="Save"/>
```

But what if you want this?

```php
<h3>Title</h3>
<p>Description</p>
<button>Read More</button>
```

You cannot realistically pass that as a prop.

👉 That's where slots come in.

Basic slot (the default $slot)

Component: `card.blade.php`

```php
<div class="card">
    <div class="card-body">
        {{slot}}
    </div>
</div>
```

**Usage**

```php
<x-card>
    <h3>Post Title</h3>
    <p>Post content goes here</p>
</x-card>
```

📌 Everything between `<x-card>` and `</x-card>` becomes `$slot`

Think of slots like this:

```php
function card ($content){
    echo $content;
}
```

**Blade Version**

```php
{{$slot}}
```

**Named slots (when one slote is not enough)**

Sometimes you want structure, not just content.

**Component**

```php
<div class="card">
    <div class="card-header">
        {{$header}}
    </div>

    <div class="card-body">
        {{$slot}}
    </div>
</div>
```

**Usage**

```php
<x-card>
    <x-slot name= "header"> <!--Call $slot only-->
        Post Details
    </x-slot>
    <p>This is the post body</p>
</x-card>
```

📌 `$slot` = body
📌 `$header` = named slote

### Notice

> Totally we use <x-slot="somthing"> when we want to multiple line of html to a property. Like we want to insert style, link, icon ..etc.

### When should we use slots?

✅ Use slots for:

- Cards
- Layout wrapper
- Modals
- Dropdowns
- Panels
- Page sections

❌ Don't use slot for:

- Input
- Buttons
- Simple UI elements

**Those are better with props only.**

### Very common real example

```php
<x-layout>
    <h1>Dashboard</h1>
    <p>Welcome back</p>
</x-layout>
```

### Inside Layout

```php
<body>
    {{slot}}
</body>
```

This is how Laravel layouts work internally.

**_One Line Summary_**

> Slot let you inject HTML content into blade components.
