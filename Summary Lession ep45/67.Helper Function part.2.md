### 3. `collect()` helper function (Collections)

**The Problem with arrays**

> PHP arrays are powerful but hard to read for complex logic.

Turn an array into a collection

```php
$numbers = collect([1,2,3,4,5]);
```

Now you can :

```php
$numbers->filter(fn($n)=> $n >2);
```

Common collection method

```php
collect($users)->pluck('email');
collect($post)->count();

collect($post)->where('status',1);
collect($post)->nap(fn($p)=> $p->title);

```

Why Collections are important

- Readable
- Chainable
- Expressive
- Used everywhere in Laravel

> **Eloquent results are already Collection**

### Where can we use helpers ?

- Controller
- Models
- Blade views
- Job/Services

They are globle, always available.

### One-Line takeaway

> Laravel helpers help you write cleaner, safer, and more readable code with less effort.

## Helpers vs Raw PHP (important comparison)

| Task        | Laravel helper | Raw PHP                     |
| ----------- | -------------- | --------------------------- |
| Null safety | `optional()`   | `if()` check                |
| Strings     | `str()`        | `str_replace()`, `substr()` |
| Arrays      | `collect()`    | loops                       |
| Arrays      | `Arr::get()`   | `isset()` and array access  |

String example:

```php
$title = str($post->title)->trim()->limit(50);
```

Array example:

```php
$city = Arr::get($user, 'address.city', 'Unknown');
```
