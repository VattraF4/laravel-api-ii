## Laravel Queues?

### 1. A queue means:

> "Don't do this work now - do it later."

Instead of executing a job immediately, Laravel:

- Stores it somewhere (database , Redis, etc.)
- Executes it in the background.

### 2. Why Queues Exist (Real Problem)

Without queues:

```php
Post::create();
Mail::to($user)->send(new NewPostMail());
Image:resize():

```

- The user waits ⌛
- The request is slow ❌
- Bad UX (User Experience) ❌

### 3. What Queue sovle

Queue allow you to:

- Respond fast to the user
- Move heavy work to background
- Handle spikes in traffic
- Retry failed tasks automatically

### 4. Job + Queue Relationship (Important)

A Job defines what to do

A Queue defines when and where it runs

So:

- Job = Task
- Queue = Background execution system.

### 5. How Laravel Knows a Job Should be Queued

You add one interface:

```php
use Illuminate\Contracts\Queue\ShouldQueue;

class ProcessPost implements ShouldQueue{
    public function handle(){
        // runs in the background
    }
}
```

That's it.

- Laravel now pushes this job to the queue instead of running it immediately.

### 6 Setting Up Database Queue (Laravel 12)

- Step 1: Set queue driver

```env
QUEUE_CONNECTION=database
```

- Step 2: Create queque table

```bash
php artisan queue:table
php artisan migrate
```

This is creates:

jobs

This table stores:

- Job class
- Payload (data)
- Attempst
- Timestamps

### 7. Dispatching a Queued Job

```php
ProcessPost::dispatch($post);
```

What happens:

- Job is inserted into jobs table in database
- Not executed yet

### 8. Running the Queue Worker

Jobs won't run until you start a worker:

```bash
php artisan queque:work
```

**This Command:**

- Listens for new jobs
- Executes them one by one
- Removes them when done

### 9. Real Flow (very Important)

1. User sends request
2. Controllers dispatches job
3. HTTP response is returned immediately
4. Worker picks job from queue
5. Job runs in background

### 11. When SHOULD we use Queues?

- ✅ Sending Emails
- ✅ Notifications
- ✅ Image processing
- ✅ Reports & Exports
- ✅ External API calls

**Not For**

- Simple CRUD ❌
- Lightweight logic ❌

**_Example:_**

```php
public function handle():void{
    $users = User:whereIn('id' ,$this ->userIds)->get();

    foreach($users as $user){
        Mail::to($user -> email)-> send(new WelcomeMail());
    }
}
```
