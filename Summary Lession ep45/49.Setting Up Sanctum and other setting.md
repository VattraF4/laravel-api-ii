## 🔐 Authentication for APIs (Laravel Sanctum)

### What is API Authenticatin & Why Sanctum?

#### ❓Why APIs Need Authentication ?

Unlike Blade apps:

- APIs are stateless
- No sessions
- No cookies (usually)

📌 APIs use tokens, not sessions.

> " Every API request must prove who you are."

#### ❓ Why Laravel Sanctum?

Laravel Sanctum provides:

- API token authentication
- Simple setup
- First-party Larvel support
- Works perfectly with mobile apps, SPAs, Postman

** Sanctum is ideal for:**

- REST APIs
- Mobile apps
- Single-page appp (React/Vue)

## Installing & Configuring Sanctum

### 1. Install Sanctum

```bash
compose require laravel/sanctum
```

### 2. Publish Config

```bash
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"
```

### 3. Run Migrations

```bash
php artisan migrate
```

**This creates:**
📃 personal_access_tokens table

### 4. Add Sanctum Middleware (Laravel 12)

`Old Larvel Version`

**Open**:
`app\Http\Kernal.php`

Ensure this exists in api milldeware group:

`\Laravel\Sanctum\Http\Middleware\EnsureFrontendRequestsAreStatful::class`

​📌​ For token-based APIs, this is usually already set.

**_Important Make sure User model uses HasApiTokens_**

📁 app/Models/User.php

```php
use Laravel\Sanctum\HasApiTokens;
class User extends Authenticatable
{
    use HasApiTokens;
}
```
