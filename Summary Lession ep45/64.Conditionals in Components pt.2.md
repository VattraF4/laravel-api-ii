### 5. When NOT to use conditionals in Components

- Database queries
- Complex decisions


**Components Should:**

- handle UI logic
- stay lightweight

**Controllers & Service handle:

- Decisions
- Data fetching

### Real-World Examples

- **Navbar:** show Login/Logout

- **Button:** show Edit only if allowed
- **Alerts:** show success or error
- **Badges:** show status (active/inactive)

### One-Liner
> Conditional rendering lets components decide when and how they appear, keeping Blade view clean and reusable.
