## Pagination in APIs (Laravel)

### Why pagination is mandatory in APIs

**Without pagination:**

- Large responses = Slow API
- High memory usage
- Bad mobile performance

💡 APIs must always pagination lists.

**Basic API pagination (Eloquent)**

```php
$posts = Post::paginate(10):
```

This will returns 10 items per page.

### Pagination with API Resource (BEST PRACTISE)

```php
use App\Http\Resources\PostResource;

public funtion index(){
    $post = Post::paginate(10)->get();
    return PostResource::collection($post);
}
```

- Clean data
- Automatic paginataion metadata
- Standard JSON Format
- Changing page size (query param)
- Laravel automatically supports:

GET `/api/posts?page=2`

**API pagination response structure**

```json
{
    "data": [
        {
            "id": 1,
            "title": "Create Post via API",
            "subtitle": "Post by raw",
            "body": "Love you babay!!",
            "user": {
                "id": 1,
                "name": "Test User",
                "email": "test@example.com"
            }
        }
    ],
    "links": {
        "first": "http://127.0.0.1:8000/api/posts?page=1",
        "last": "http://127.0.0.1:8000/api/posts?page=1",
        "prev": null,
        "next": null
    },
    "meta": {
        "current_page": 1,
        "from": 1,
        "last_page": 1,
        "total": 5
    }
}
```

📌 Clients (Mobile/ Fronted) rely on this meta data

### Simple Pagination (When links not needed)

```php
Post::simplePaginate(10);
```

- ✅ Faster
- ❌ No total count
- ❌ No last page

**Use for:**

- Infinite scroll
- Feeds (e.g: news feed)

### Cursor Pagination (Large datasets)

```php
Post::cursorPaginate(10);
```

- Best performance
- Used by big apps (Twitter, Instagram)
- ❌ No page numbers

### Filtering + Pagination (Real-World)

```php
Post::where('status',1)
        ->with('user')
        ->paginate(10);
```

### Pagination + Relationships (IMPORTANT)

**Always eager load:**

```php
Post::with('user')->paginate(10);
```

- ❌ Lazy Loading = N+1 problem
- ✅ Clean SQL

_DO NOT DO THIS ❌_

```php
Post::all(); //API Killer
get()->paginate(); // Wrong;
```

### Controller Best Practice
```php
public function index(){
    $posts=Post::with('user')->paginate(10);
    $return PostResource::collection($posts);
}
```
---
### One-line teaching summary

> Pagination limits API responses and provides metadata so clients can load data efficiently.

### Real World API rule

> Every API endpoint that returns a list MUST be paginated.
