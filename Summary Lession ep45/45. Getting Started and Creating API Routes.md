### Creating API Route (api.php)

(Laravel 12 - Beginner -> Intermediate)

### 1. What is api.php ?

Laravel Separates web routes and api routes.

| File           | Purpose                           |
| -------------- | --------------------------------- |
| routes/web.php | Blade pagfes, sessions, redirects |
| routes/api.php | APIs, JSON responsed, stateless   |

Go get api.php file use command:

```bash
php artisan install:api
```

📌 Key Rule:

> "If it return JSON, it belongs in api.php"

### 2. What makes API Routes Different?

- API routes are automatically: - Prefixed with /api - Stateless
    > > Group under the api middleware

### Example:

```php
Route::get('/post',function(){
    return ['message' => "Hello API"];
});
```

`URL:`

- Get: /api/posts

### 3. Basic API Route Example:

```php
use Illuminate\Support\Facades\Route;
Route::get('/users',function(){
    return [
        'status' => true,
        'data' => [
            ['id' =>1, 'name'=>'Ra Vattra'],
            ['id' =>2, 'name'=>'Yan Pich'],
        ],
        'message'=>'success'
    ];
});
```

📌 Laravel automatically converts arrays to JSON.

### 4. API Routes with Controllers (Recommand)

Inline routes are okey for learning - controllers are for real apps.

```bash
php artisan make:controller Api/PostController
```

```php
use App\Http\Controllers\Api\PostControllers;

Route::get('/posts', [PostController::class, 'index']);

```

### Controller:

```php
class PostController extends Controllers{
public function index()
    {
        return [
            'status' => true,
            'posts' => [
                ['id' => 1, 'title' => 'My first post', 'content' => 'This is the content of my first post'],
                ['id' => 2, 'title' => 'My second post', 'content' => 'This is the content of my second post'],
            ],
            'message' => 'success'
        ];
    }
}
```

### 5. RESTFul API Routes

REST APIs follow resource-based routing

```php
Roue::get('/posts',...);            //list posts
Roue::post('/post',...);            //create post
Roue::get('/posts/{post}',...);    //show post
Roue::put('/posts/{post}',...);    //update post
Roue::delete('/posts/{post}',...);    //delete post
```

📌 Teaching Line:

> > "The URL statys the same - the HTTP method changes."

### 6. API Resource Routes (Preview Only)

(We'll go deeper later - just introduce it)

```php
Route::apiResource('posts', PostController::class);
```

Generates:

- index
- store
- show
- update
- destroy

❌ No create or edit (because APIs don't return views).

### 7. Testing API Routes

APIs are not visible in the browser.

Use:

- Postman
- Insomnia
- cURL

Example:

GET: http://127.0.0.1:8000/api/posts

### 8. Common Beginner Mistakes (Important Slide)

- ❌​​ Returning Blade views
- ❌​​ Using web.php for APIs
- ❌​​ Redirecting after POST
- ❌​​ Using session

- ✅ Always return JSON
- ✅ Use status codes

### 9. Teaching Summary (End of Lecture)

> > "Today we didn't build logic - we built the foundation. API live in `api.php`, return JSON, and follow REST rules"
