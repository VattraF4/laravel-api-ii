## Sending Emails with Mailables (Laravel 12 - Web Context)

### What is a Mailable?

A Mailable is a class that represents an Email.

**Instead of:**

- Writing email HTML in controllers ❌
- Mixing logic with view ❌

**Laravel Lets you:**

- Create a dedicated email class
- Attach a Blade view

### Pass data cleanly:

📌 Think of a Mailable as a ViewModel for emails.

### Why Mailables are important?

**Without Mailables:**

```php
Mail::raw('Hello', function ($mail){
    $mail->to($user->email);
});
```

**With Mailables:**

- Clean Structure
- Reusable emails
- Easy to queue later
- Easy to test

### \# Real World Standard

### Step 1: Configure mail (web app context)

_In .env (Example with Mailtrap):_

```env
MAIL_MAILER=log
#MAIL_SCHEME=null
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=xxxx
MAIL_PASSWORD=xxx
MAIL_FROM_ADDRESS="no-reply@example.com"
MAIL_FROM_NAME="${APP_NAME}"
```

**📌 Mailtrap = Fake inbox (safe for dev)**

### Step 2: Create a Mailable

```bash
php artisan make:mail WelcomeMail
```

**Create Location 📁:**

- `app\Mail\WelcomeMail.php`
- `resources\views\emails\welcome.blade.php`

### Step 3: The Mailable class

```php
use Illuminate\Mail\Mailable;

class WelcomeMail extends Mailable
{
    use Queueable, SerializesModels;

    public string $username;
    /**
     * Create a new message instance.
     */
    public function __construct(string $name)
    {
        $this->username = $name;
    }

    /**
     * Get the message content definition.
     */
    public function content(): Content
    {
        return new Content(
            view: 'view.emails.welcome',
        );
    }

}

```

- ✅ Data injected cleanly
- ✅ No logic in controller

### Step 4: Email Blade view

```html
<h1>Welcome, {{$username}}</h1>
<p>Thanks for joining our platform.</p>
```

📌 This is normal Blade, just used for email.

### Step 5: Sending Email (Controller)

```php
use App\Mail\WelcomeMail;
use Illuminate\Support\Facades\Mail;

class EmailController extends Controller
{
    public function sendWelcomeEmail()
    {
        $name = auth()->user()->name;
        $email = auth()->user()->email;

        // Send the welcome email
        Mail::to($email)->send(new WelcomeMail($name));
        return response()->json(['message' => 'Welcome email sent successfully.']);
    }
}
```

- Simple
- Readable
- Professional

**Where should this be triggered in a web app>**

_Common real-world cases:_

- After registration
- After password reset
- After order creation
- After contact form submission

Example (Registration):

```
Mail:to($user->email)->send(new WelcomeMail($user->name));

```

**Important Rule** 🚨

- ❌ Never send emails inside loops
- ❌ Never send emails heavy emails synchronously in production.
